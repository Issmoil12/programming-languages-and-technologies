ЛАБОРАТОРНАЯ РАБОТА № 7
Создание простого одностраничного приложения (SPA) без фреймворков

Дисциплина: Языки и технология программирования

Технологии: HTML5, CSS3, JavaScript

Тема: Навигация по вкладкам и динамическая смена содержимого без перезагрузки страницы.

1. Цель работы

Изучить принципы создания одностраничных веб-приложений (SPA) без использования фреймворков. Освоить работу с DOM, обработку событий, динамическое формирование содержимого и организацию навигации по вкладкам.

2. Используемые технологии
HTML5 — создание структуры веб-страницы.
CSS3 — оформление интерфейса и адаптация под разные размеры экрана.
JavaScript — обработка событий, управление DOM и работа с данными.
Visual Studio Code — разработка и редактирование исходного кода.
GitHub — хранение исходного кода проекта.
3. Выполнение работы
3.1. Вариант № 10 — «Список задач» (средний уровень)

Разработано одностраничное приложение для управления списком задач.

Основные возможности:

отображение всех задач;
отображение только активных задач;
отображение выполненных задач;
добавление новых задач через форму;
изменение статуса задачи с помощью флажка;
удаление задач;
подсчёт общего количества задач и выполненных задач;
динамическое обновление содержимого без перезагрузки страницы.

Данные задач представлены в виде массива объектов JavaScript. Каждая задача содержит идентификатор, название и статус выполнения.

Для переключения вкладок используются обработчики событий addEventListener(). Для отображения данных применяется динамическое создание DOM-элементов.

3.2. Вариант № 20 — «Управление мероприятиями» (повышенный уровень)

Разработано одностраничное приложение для управления мероприятиями и регистрации участников.

Приложение содержит три вкладки:

События — добавление и удаление мероприятий, указание даты и места проведения.
Регистрация — ввод имени и электронной почты участника, выбор мероприятия и проверка введённых данных.
Участники — отображение зарегистрированных участников и возможность их удаления.

Дополнительные возможности:

проверка обязательных полей форм;
проверка корректности даты мероприятия;
проверка формата электронной почты средствами HTML;
предотвращение повторной регистрации одного адреса электронной почты на одно мероприятие;
динамическое обновление списка участников;
удаление участников при удалении соответствующего мероприятия.

Информация о мероприятиях и участниках хранится в массивах объектов JavaScript.

4. Структура проекта

Каждый вариант проекта состоит из трёх основных файлов:

index.html — структура страницы и навигация;
style.css — оформление интерфейса;
app.js — логика приложения и обработка событий.

Дополнительно используется файл report.md, содержащий описание лабораторной работы.

5. Принцип работы SPA

При открытии страницы загружаются HTML-разметка, стили и JavaScript-код. При нажатии на вкладку обработчик события определяет выбранный раздел и вызывает функцию отображения соответствующего содержимого.

JavaScript изменяет элементы DOM без полной перезагрузки страницы. Для безопасного вывода пользовательских данных применяется свойство textContent, а для создания элементов — метод document.createElement().

Визуальное выделение активной вкладки выполняется с помощью CSS-класса active.

В ходе тестирования необходимо проверить следующие сценарии:

переключение между тремя вкладками;
изменение статуса задачи;
удаление задачи;
корректность счётчика задач;
отображение сообщения при отсутствии задач.
Вариант № 20
создание мероприятия с заполненными полями;
проверка обязательных полей;
проверка даты мероприятия;
регистрация участника;
проверка электронной почты;
предотвращение повторной регистрации на одно мероприятие;
отображение списка участников;
удаление участника и мероприятия;
переключение между вкладками без перезагрузки страницы.
7. Результаты работы

В результате лабораторной работы разработаны два учебных SPA-приложения разного уровня сложности с использованием HTML5, CSS3 и JavaScript без сторонних фреймворков.

В ходе выполнения работы закреплены навыки создания DOM-элементов, обработки событий, работы с массивами объектов, фильтрации данных, проверки форм и динамического обновления интерфейса.

8. Заключение

Цель лабораторной работы достигнута. Были изучены основные принципы создания одностраничных приложений без фреймворков, реализована навигация по вкладкам и динамическое изменение содержимого страницы.

Средний вариант позволил освоить управление задачами и фильтрацию данных, а повышенный вариант — работу с формами, регистрацию участников и проверку вводимой информации.

Полученные знания могут быть использованы при разработке более сложных клиентских веб-приложений.
